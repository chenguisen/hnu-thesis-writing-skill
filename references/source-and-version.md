# 来源、提取方法与版本说明

## 1. 来源文件

- 文件名：`湖南大学论文撰写规范.doc`
- 格式：Word 97-2003 二进制文档（OLE 复合文档）
- 大小：1,051,936 字节
- 文档元数据：创建于 2005-08-31；标题为格式控制符（视为空）；作者 `yj`；最后修改者信息不具版本意义。
- 原文件未随本仓库分发；如需核对原文，请向湖南大学研究生院或学院索取当前版本。

## 2. 提取方法

1. 使用本机 WPS 的 COM 接口把 `.doc` 另存为 `.docx`（保留段落、表格、样式）。
2. 用 `python-docx` 按文档流顺序导出全部段落与 11 个表格到纯文本，逐节人工核对。
3. 从 `.docx` 读取节属性、样式、字号、对齐、段前段后，作为版式指标的交叉验证。
4. 按“结构 / 版式 / 引用 / 检查清单”四个维度重组为可执行 skill；不改变规范原意。

> 原 `.doc` 与本 skill 的转换副本不纳入公开仓库：规范文本的著作权归湖南大学，本仓库只收录
> 整理后的操作指引与自检代码。

## 4. 版本与效力

- 本 skill 以 2005 版规范文本为**基线**，不是湖南大学研究生院的官方发布物。
- 学位论文的最终格式要求以**研究生院/学院当年发布的模板与通知**为准；两者冲突时，模板优先。
- 若新版规范调整了字数、参考文献数量、页边距、页眉或摘要格式，按新版修改本 skill 的
  `SKILL.md` 速查表与对应 reference 文件，并在本文件记录日期与差异。
- 建议每次使用前做一次“模板对照”：打开学校模板，核对页面设置、样式字号、页眉页脚、页码分节。

## 5. 维护清单（给后续维护者）

更新本 skill 时同步修改：

1. `SKILL.md` 的“硬指标速查”和“已知矛盾”。
2. `references/structure.md` 的字数、篇数、摘要长度。
3. `references/formatting.md` 的页面、字体、页眉、页码。
4. `references/citations.md` 的著录格式与标准号。
5. `scripts/thesis_lint.py` 中的 `DEGREES` 常量与检查阈值。
6. `tests/fixture_master.docx` 与 `tests/test_lint.py` 的回归断言。
7. 本文件的“版本与效力”日期。
