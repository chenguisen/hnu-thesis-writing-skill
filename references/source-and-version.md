# 来源、提取方法与版本说明

## 1. 来源文件

- 文件名：`湖南大学论文撰写规范.doc`
- 格式：Word 97-2003 二进制文档（OLE 复合文档）
- 大小：1,051,936 字节
- 文档元数据：创建于 2005-08-31；标题为格式控制符（视为空）；作者 `yj`；最后修改者信息不具版本意义。
- 原文件未随本仓库分发；如需核对原文，请向湖南大学研究生院或学院索取当前版本。

## 2. 提取方法

1. 使用本机 WPS 的 COM 接口把 `.doc` 另存为 `.docx`（保留段落、表格、样式）。
2. 用 `python-docx` 按文档流顺序导出全部段落与 11 个表格到纯文本，逐节人工核对。
3. 从 `.docx` 读取节属性、样式、字号、对齐、段前段后，作为版式指标的交叉验证。
4. 按“结构 / 版式 / 引用 / 检查清单”四个维度重组为可执行 skill；不改变规范原意。

## 2.1 第二个来源：一份答辩通过的博士论文（只取版式）

2005 版规范只给了前置部分的文字要求（“封面用学校固定格式”“1 号黑体”等），没有可执行的
逐行清单；为补上这一块，另外用一份 2025 年答辩通过的湖南大学博士学位论文（材料科学与
工程学院）做了结构实测：

- 读取方式：`zipfile` + `lxml` 直接解析 `word/document.xml`、`styles.xml`、`numbering.xml`、
  `header*.xml`、`footer*.xml`，不打开、不修改原文件。
- 提取内容：分节与页码格式、页眉页脚、封面/内封各行内容与字号缩进、声明页、目录与索引域代码、
  题注域结构、表格边框、样式定义。
- 数值换算：OOXML 的 twips → mm/pt（1 twip = 1/1440 英寸）。
- **未收录**该论文的题目、姓名、导师、正文、图表、参考文献或任何个人数据；仓库里只有
  版式规则和占位符骨架。
- 该文件本身有 3 处残留问题（旧论文页眉、`xx 教授` 占位、页眉继承），记录在
  `front-matter.md` 第 9 节，作为“答辩通过也未必零瑕疵”的提醒。

### 2.1.1 从这份论文实测到的一条字体规则

规范正文只写“正文小 4 号宋体”，没有单独规定西文用什么。但该论文的样式定义是：

| 样式 | 中文字体（`w:eastAsia`） | 西文字体（`w:ascii`） |
|---|---|---|
| `Normal` | 宋体 | Times New Roman |
| `Heading 1–4` | 黑体 | Times New Roman |
| `Caption`（题注） | 黑体 | Times New Roman |

也就是说“中文用中文字体、西文与数字用 Times New Roman”。附件里若把 `w:ascii` 设成宋体，
英文与数字会用中文字体排（字宽、字距、换行都与模板不同）；这是从中文 Word 复制内容、
或从别人论文里贴段落时最常见的问题。已据此补上 `formatting.md` 第 2.1 节、
自检规则 `FONT-07` 和修正脚本 `scripts/fix_latin_fonts.py`。

## 2.2 脚本能做什么、不能做什么

- `scripts/extract_front_matter.py`：定位源文档正文第 1 章（Heading 1 + 自动编号），把前面
  所有块 `deepcopy` 进新文档，再按标签替换文字（学号、姓名、导师、题目、日期、摘要正文、
  关键词），并清掉旧的页眉题目、把声明页页眉统一成摘要节的正确页眉。**不做版式换算**，
  所以段落属性与原文件逐字节一致；这也是它能保证“间距、对齐不走样”的原因。
- 只替换文字，不重排：如果新题目比原题目短，分页位置会变（例如原封面题目两行、新题目一行），
  这是文本长度变化，不是版式被改。
- 域的结果仍是原文档的缓存值：打开后 Ctrl+A → F9 重算目录/索引；WPS 也要手动更新。
- 生成器不能判断“原文档本身是否正确”。抽取前先用 `thesis_lint.py` 检查源文件；
  源文件里的错误（例如旧页眉、`xx 教授` 占位）会被一并继承，脚本只修了页眉文字这一项。

> 原 `.doc` 与本 skill 的转换副本不纳入公开仓库：规范文本的著作权归湖南大学，本仓库只收录
> 整理后的操作指引与自检代码。

## 4. 版本与效力

- 本 skill 以 2005 版规范文本为**基线**，不是湖南大学研究生院的官方发布物。
- 学位论文的最终格式要求以**研究生院/学院当年发布的模板与通知**为准；两者冲突时，模板优先。
- 若新版规范调整了字数、参考文献数量、页边距、页眉或摘要格式，按新版修改本 skill 的
  `SKILL.md` 速查表与对应 reference 文件，并在本文件记录日期与差异。
- 建议每次使用前做一次“模板对照”：打开学校模板，核对页面设置、样式字号、页眉页脚、页码分节。

## 5. 维护清单（给后续维护者）

更新本 skill 时同步修改：

1. `SKILL.md` 的“硬指标速查”和“已知矛盾”。
2. `references/structure.md` 的字数、篇数、摘要长度。
3. `references/formatting.md` 的页面、字体、页眉、页码。
4. `references/citations.md` 的著录格式与标准号。
5. `references/cross-references.md` 的题注/书签/REF 域操作。
6. `references/front-matter.md` 的封面/内封/声明/目录/索引版式与分节页码。
7. `scripts/thesis_lint.py` 中的 `DEGREES` 常量与检查阈值。
8. `scripts/extract_front_matter.py` 里的替换标签（封面字段、英文内封字段、摘要/关键词）。
9. `tests/fixture_master.docx`、`tests/test_lint.py`、`tests/test_extract_front_matter.py` 的回归断言。
10. 本文件的“版本与效力”日期。
