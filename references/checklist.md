# 提交前检查清单

打印本页或在副本上逐项打勾。机器可查项先运行：

```bash
python scripts/thesis_lint.py thesis.docx --degree master
```

`thesis_lint.py` 只能查结构与常见字体/页面问题，**签名、印刷、装订、内容质量仍需人工确认**。

## A. 前置部分

- [ ] 封面使用研究生院当前模板，白色铜版纸。
- [ ] 学校代号、分类号、密级、学号（同等学力受理单编号）填写完整。
- [ ] 论文题目 ≤25 字，不设副标题，封面/内封/摘要页题目一致。
- [ ] 中文内封字段完整：姓名、导师及职称、培养单位、专业、提交日期、答辩日期、答辩委员会主席。
- [ ] 英文内封的学位级别、学科门类、学科名称、导师、日期拼写正确。
- [ ] 原创性声明、版权使用授权书**手写签名**，日期完整。
- [ ] 保密/不保密选项已勾选；保密论文填写解密年份。
- [ ] 中文摘要约 600/1200 字，有创造性成果与意义，不含公式、图表、文献编号。
- [ ] 中文关键词 3～8 个，分号分隔，按外延从大到小。
- [ ] 英文摘要与中文摘要内容一致，语法、用词正确。
- [ ] 英文关键词与中文关键词一一对应。
- [ ] 目录更新到最新，含摘要、Abstract、索引、正文至 3 级、结论、参考文献、附录、致谢。
- [ ] 目录页码与正文实际页码一致（前置罗马、正文阿拉伯）。
- [ ] 插图索引、附表索引、符号表按需提供；编号与正文一致。

## B. 正文

- [ ] 每章另起一页。
- [ ] 章标题 ≤15 字，无标点，无“第 X 章”之外的编号混乱。
- [ ] 章、节、条、款编号连续，无跳号、重号。
- [ ] 标题层次全文统一（不要混用“一、”“1.”“1.1”）。
- [ ] 各级标题未落在页面最后一行（孤行）。
- [ ] 引言包含学术背景、理论/实际意义、国内外综述、课题来源、主要研究内容。
- [ ] 主体章节结构合理，理论分析、实验/实证、结果讨论完整。
- [ ] 结论单独成章，**不加章号**，指出创新点、价值与展望，约 2000 字。
- [ ] 结论没有大段复制摘要。
- [ ] 全文术语统一；缩写首次出现注明英文全称。
- [ ] 物理量符号斜体、单位正体；单位符合法定计量单位。
- [ ] 数字用法统一：年份四位；四位以上数字每三位空半格，不用千分位逗号。
- [ ] 全文没有“待补充”“TODO”“XXX”“？？？”等占位符。
- [ ] 全文没有残留的批注、修订痕迹、高亮。

## C. 图表与公式

### 图

- [ ] 每图都有图题，图题在图**下**。
- [ ] 图号按章编排（图 1.1、图 2.1），全文连续，无重号。
- [ ] 图题与图不跨页拆分。
- [ ] 引用图注明出处，文献号标在图题右上角。
- [ ] 分图用 a)、b)，分图题在分图下。
- [ ] 坐标图有横纵坐标名称和单位。
- [ ] 图片清晰度足够（建议 ≥300 dpi），无拉伸变形。
- [ ] 图中文字为中文（引用外文图除外）或数字项号。

### 表

- [ ] 每表都有表题，表题在表**上**、居中。
- [ ] 表号按章编排（表 1.1、表 2.1），全文连续，无重号。
- [ ] 使用三线表，无左右边线。
- [ ] 全表同一单位时，单位放在表头右上角并加圆括号。
- [ ] 空白数据格用“—”，不用“同上”“〃”。
- [ ] 表内文字说明起行空一格、转行顶格、句末无标点。
- [ ] 跨页表重复表头，续表标注“续表”。

### 公式

- [ ] 公式居中，编号右顶格。
- [ ] 编号按章（1.1、1.2），附录用（A.1）。
- [ ] 公式中首次出现的物理量已注释。
- [ ] 长公式转行规范，运算符只写在转行行首。
- [ ] 正文引用公式用“见式(1.1)”等统一说法。

## D. 参考文献

- [ ] 按正文首次出现顺序编号，编号连续。
- [ ] 正文标注与文后条目一一对应，无“多标”“漏标”。
- [ ] 引用标注在句末右上角，未标在标题上。
- [ ] 同一文献只占一个编号。
- [ ] 作者 ≤3 人全列；>3 人列前 3 人加“等/et al”。
- [ ] 期刊条目有年、卷(期)、起止页。
- [ ] 学位论文有条目级别、保存单位、年份。
- [ ] 会议论文有论文集名、出版地、出版者、年份、页码。
- [ ] 网络文献有发布日期/引用日期和 URL。
- [ ] 中外文标点没有混用。
- [ ] 数量达标：博士 ≥80（外文 ≥40）；学术硕士 ≥40（外文 ≥10）；专业硕士 ≥30（外文 ≥5）。
- [ ] 抽查 10 条，能在数据库中检索到原文。

## E. 附录与致谢

- [ ] 附录 A 为攻读学位期间发表的学术论文目录，格式同参考文献。
- [ ] 其他附录按 B、C、D 顺序排列，每个附录有标题。
- [ ] 附录中的公式、图、表编号带附录字母（A.1、图 A.1、表 A.1）。
- [ ] 非中文论文的详细中文摘要作为最后一个附录，标明中文题目，字数达标。
- [ ] 致谢简洁、实事求是，感谢导师、协助者、资助者。
- [ ] 致谢中没有不当表述或遗漏资助编号。

## F. 版式与打印

- [ ] A4；上/下 22 mm，左/右 25 mm（或按学院模板）。
- [ ] 页眉距边界 11 mm，页脚距边界 11 mm。
- [ ] 正文小 4 号宋体，每页约 35 行、每行约 35 字。
- [ ] 章标题小 2 号黑体居中，上下各空一行。
- [ ] 节标题小 3 号黑体，上下各空 12 磅。
- [ ] 条标题 4 号黑体，上下各空 6 磅。
- [ ] 款/项小 4 号黑体。
- [ ] 页眉小 5 号宋体；奇数页“学位论文类别”，偶数页论文题目。
- [ ] 页眉线为 1.5 磅双线，粗线在上。
- [ ] 前置部分罗马数字，从原创性声明页开始。
- [ ] 正文阿拉伯数字从 1 开始。
- [ ] 页码在版心下边线之下隔行居中。
- [ ] 前置部分单面印刷，正文双面印刷。
- [ ] 致谢、附录单面起页；正文结束页为单数时，其背面不加页眉页码。
- [ ] 装订整齐，书脊（如要求）信息正确。

## G. 电子版与提交

- [ ] 电子版与印刷版格式一致（同一份文件导出）。
- [ ] PDF 已嵌入字体，分页与 Word 一致。
- [ ] 文件命名符合学校要求（学号_姓名_题目）。
- [ ] 查重报告已出，重复率在学院要求范围内。
- [ ] 送审/盲审版本已删除作者、导师、致谢等身份信息（如要求）。
- [ ] 签字页、版权页扫描件齐全（如要求）。
- [ ] 图书馆/研究生院系统提交成功，回执已保存。

## H. 最后一遍通读

- [ ] 摘要、引言、结论三处的创新点表述一致，没有互相矛盾。
- [ ] 章节之间的过渡自然，没有“为凑字数”的重复段落。
- [ ] 所有“本文”“本研究”指代一致。
- [ ] 图表编号在正文中都被引用到（没有“孤图”“孤表”）。
- [ ] 参考文献中的每条都在正文有对应标注（没有“孤文献”）。
- [ ] 全文搜索“略”“待定”“以后补充”，确认没有遗留。
- [ ] 请一位同专业同学通读摘要和结论，确认能看懂。
