# 图、表、公式的交叉引用与跳转

## 1. 先给结论

**Word / WPS 可以实现“点击正文里的图 1.1、表 2.1、式(2.1) 跳到对应对象”**，但前提是：
编号不是手打的，而是用**题注 + 书签 + REF 交叉引用域**插入的。

本 skill 的 `thesis_lint.py` 会检查：

- 文档里有没有 `REF` 交叉引用域；
- 图题、表题是否在正文中被引用（避免“孤图/孤表”）；
- 图题、表题的编号是否连续。

它不会替你插入 Word 域；域必须在 Word/WPS 里生成。批量插入域可以用 Word 的
“插入题注 + 交叉引用”，或用宏/脚本处理，但**不要用纯文本替换**。

## 2. 图的交叉引用

1. 选中图下方的图题，如“图1.1 系统结构图”。
2. 引用 → 插入题注 → 标签选“图” → 确定。
   - 需要“图1.1”这种按章编号：题注 → 编号 → 勾选“包含章节号”，章节起始样式选“标题 1”，
     分隔符选“.”。
3. 光标移到正文要引用的位置，输入“如图”，然后引用 → 交叉引用：
   - 引用类型：图
   - 引用内容：仅标签和编号
   - 勾选“插入为超链接”
4. 继续输入“所示”。
5. 全选（Ctrl+A）→ F9 → 更新整个目录/域；导出 PDF 前再更新一次。

效果：正文显示“如图1.1所示”，**Ctrl+单击**可跳到图 1.1；插入/删除图后编号自动更新。

### 2.1 坑：交叉引用会把题注的黑体带到正文

题注是黑体小四，正文是宋体小四。REF 域更新时，Word/WPS 默认**把书签处（题注）的字符格式
套到域结果上**，于是正文里的“图1.1”“表2.1”变成黑体——更新一次域就出现一次，
看起来像“正文里混进了黑体”。两种处理：

1. **加 `\* MERGEFORMAT` 开关**（推荐）：把域代码改成
   `REF _Ref12345 \h \* MERGEFORMAT`，再手动把域结果设成宋体小四。之后每次 F9，
   域会保留自己这一份格式，不再跟着题注走。
   - 域代码怎么看：选中引用 → `Shift+F9` 切换；或 文件 → 选项 → 高级 → 勾选“显示域代码”。
2. **更新后再改一次**：每次 F9 之后把正文里的黑体再刷成宋体——能用，但容易漏。

`thesis_lint.py` 的 `FONT-08` 就是查这个：正文段（非标题、非题注）里出现黑体时告警，
并提示用 `\* MERGEFORMAT` 处理。

### 2.2 坑：题注里的希腊字母变成全角字形

题注常带 `δ相`、`γ′/γ″层`、`850 ℃` 这类内容。若题注 run 带 `w:hint="eastAsia"`，
Word/WPS 会用**黑体**去排希腊字母、`℃`、`″`，得到的全角字形又宽又大，`γ″` 之间还会
撑出一个汉字宽的空当；而正文里同一个 `δ` 是 Times New Roman——**同一符号两种字形**，
评审一眼就能看出来。索引（`TOC \c`）、附表索引、表格单元格同理会变成宋体全角。

- 判据与修法见 `formatting.md` 第 2.1.1 节：只给符号段去掉 `w:hint`，汉字段保留。
- 批量修：`python scripts/fix_symbol_fonts.py thesis.docx --in-place`。
- 查：`thesis_lint.py` 的 `FONT-09`。
- **顺序很重要**：先改题注 → 再更新域（F9 / 目录更新，页码才会重排）→ 最后再跑一次
  `fix_symbol_fonts.py`。因为目录、插图索引是域结果，更新时按题注重新生成，会把这些
  字符的格式一起重置；反过来先更新域再改字体，字体就稳住了。

## 3. 表的交叉引用

与图相同，区别是：

- 表题在表的**上方**；
- 题注标签选“表”；
- 正文写法通常为“如表2.1所示”；
- 表格跨页时仍只对**一个表题**做交叉引用，续表不另起书签。

## 4. 公式的交叉引用

公式没有“题注”对象，常用两种做法。

### 4.1 推荐：书签 + 交叉引用

1. 用一行三列的**无边框表格**排公式：
   - 左列空；
   - 中列放公式（居中）；
   - 右列放编号，如“(2.1)”，右对齐。
2. 选中右列编号“(2.1)”（只选编号，不选公式）→ 插入 → 书签，命名如 `eq_2_1`。
3. 正文要引用处 → 插入 → 交叉引用 → 引用类型“书签” → 选择 `eq_2_1` →
   引用内容“书签文字” → 勾选“插入为超链接”。
4. 更新域并检查 Ctrl+单击跳转。

优点：编号可以手打或域生成，书签始终可跳；缺点：插入新公式后编号不会自动重排，
需要手工调整或使用 SEQ 域。

### 4.2 自动编号：SEQ 域（进阶）

公式编号可以用域自动生成，例如：

```text
( { STYLEREF 1 \s }.{ SEQ 公式 \* ARABIC \s 1 } )
```

- `STYLEREF 1 \s` 取当前“标题 1”的章号；
- `SEQ 公式` 按章重新编号；
- 花括号必须用 **Ctrl+F9** 插入的域括号，不能手打 `{}`；
- 改完后 Ctrl+A → F9 更新。

不熟悉域代码时，优先用“书签 + 手打编号”，至少保证跳转；编号一致性用
`thesis_lint.py` 和人工检查兜底。

## 5. 答辩通过的论文是怎么做的（实测域代码）

下面是从一份 2025 年答辩通过的湖南大学博士论文 XML 里读出的题注结构，可以直接照抄：

```text
图{  STYLEREF 1 \s }.{  SEQ 图 \* ARABIC \s 1 } 图题文字
表{  STYLEREF 1 \s }.{  SEQ 表 \* ARABIC \s 1 } 表题文字
```

- `STYLEREF 1 \s` 取“标题 1”所在段的**自动编号**（章号）。所以章标题必须用标题样式
  并挂自动编号；手打“第1章”时 STYLEREF 取不到章号，题注会显示成“图.1”。
- `SEQ 图 \* ARABIC \s 1` 是章内序号，`\s 1` 表示每遇到 1 级标题就从 1 重新开始。
- 题注段落用“题注”样式：12 磅黑体、居中、段前段后 6 磅（答辩版实测）。
- **书签只包编号**（`图1.1` 这一段）：`图` + STYLEREF + `.` + SEQ。这样正文 REF 只带出
  “图1.1”，不会把图名也拖进句子。
- 正文写 `如图 { REF _Ref12345 \h } 所示`；`\h` 让引用成为超链接，Ctrl+单击跳转。
- 插图索引 `TOC \h \z \c "图"`、附表索引 `TOC \h \z \c "表"` 会按 SEQ 标签收集题注，
  F9 后自动重排；目录 `TOC \o "1-4" \h \z \u`。

手打编号 + 书签也能跳转，但插/删图后要人工重排；上面的写法是“编号自动 + 可跳转 +
有索引”三者兼得，推荐优先用。前置部分的域与索引细节见 `front-matter.md`。

## 6. WPS 的操作差异

WPS Writer 也有“引用 → 交叉引用”，步骤与 Word 接近：

- 图/表：先插入题注，再交叉引用；
- 公式：WPS 的交叉引用类型可能没有“公式”，用**书签 + 超链接**最稳；
- 导出 PDF 时勾选“创建书签”“保留超链接”，导出后点一下确认链接还在。

## 7. 怎么验证真的能跳

1. Word/WPS 中按住 **Ctrl** 单击正文中的“图1.1/表2.1/式(2.1)”，应跳到对象所在页。
2. 在对象前插入一张图/一个表，Ctrl+A → F9，正文编号应自动变化。
3. 删除被引用的图/表，正文应出现“错误！未找到引用源”之类提示；这说明它是域而不是手打文本。
4. 导出 PDF 后，用阅读器点击链接，确认跳转保留。

## 8. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 正文“图1.1”不能点 | 手打文本，不是交叉引用域 | 删掉重插交叉引用 |
| 插入新图后编号不变 | 没有更新域 | Ctrl+A → F9 → 更新整个目录/域 |
| 显示“错误！未找到引用源” | 书签/题注被删，或复制粘贴破坏域 | 重新插入题注/书签，再插交叉引用 |
| 复制章节后交叉引用指向旧对象 | 书签被复制成重名 | 删除重复书签，重新插入引用 |
| 转 PDF 后链接消失 | 导出设置未保留超链接/书签 | 重新导出，勾选保留链接与书签 |
| 题注显示“图.1” | 章标题是手打的“第1章”，STYLEREF 取不到自动编号 | 给章标题挂自动多级编号，或改用“包含章节号”的题注 |
| 正文引用带出整条图名 | 书签把图题一起包进去了 | 书签只包“图1.1”，重新插入 REF |
| 盲审版出现“图1.1”断链 | 删除了原图但正文还引用 | 用 `thesis_lint.py` 的孤图/孤表提示逐条清理 |

## 9. 与学校规范的关系

2005 版规范只规定图题、表题的位置与编号方式，**没有强制要求超链接**；但用交叉引用可以同时满足：

- 编号按章自动生成，减少手改错误；
- 正文引用与图/表/公式一一对应；
- 电子版阅读时可直接跳转，送审/答辩更方便。

因此建议：**图、表、公式编号一律用题注或书签 + 交叉引用，不手打编号**。
